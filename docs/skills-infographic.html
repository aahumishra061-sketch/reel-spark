The Arc

Every phase built the muscle the capstone needed later.

The first fifty days weren't separate from the last ten — they were the reason the last ten worked.

Weeks 1–2

AI Foundations & Effective Prompting

Learned how large language models actually respond to instruction — precision, context, and structure over guesswork. This became the backbone of every AI prompt written for Reel Spark's scoring and rewriting engine.

Weeks 3–4

Reasoning & Research Workflows

Practiced breaking ambiguous problems into steps and verifying claims before acting on them — the same discipline used to diagnose a hosting failure and a security incident mid-capstone without panic.

Weeks 5–6

Automation & Product Thinking

Moved from "can I build this" to "should I build this, and for whom" — the thinking that produced Reel Spark's explicit v1.0 scope before a single line of code existed.

Weeks 7–8

Increasingly Sophisticated AI Projects

Built progressively harder AI-integrated tools, each one adding a layer — real APIs, structured outputs, error handling — that later became load-bearing parts of the capstone's architecture.

Weeks 9–10

Knowledge Systems & Multimodal AI

Worked with structured data and mixed input types — groundwork for parsing real PDF and DOCX resumes into clean text the AI could reliably reason over.

Weeks 11–12

Autonomous Agents & Multi-Agent Collaboration

Explored systems that plan and act with less hand-holding — the same mindset behind designing a Cloudflare Worker that independently and securely brokers every AI request Reel Spark makes.

Days 51–60 · The Capstone

Reel Spark — Everything, Together

Ten days that pulled every prior skill into one real, production, publicly-shippable product.

● Shipped & Live

Ten days. One real engineering project.

Not a tutorial clone — an AI product with real constraints, a real security incident, and real decisions made under them.

Pivot

Switched the AI provider from Claude to Gemini mid-build once the free-tier budget constraint became clear — and rebuilt the integration cleanly.

Security

An exposed API key was auto-revoked by Google within minutes. Response: architected a Cloudflare Worker proxy so the key never touches the frontend again.

Resilience

Netlify's infrastructure failed mid-sprint through no fault of the build. Migrated to GitHub Pages same-day rather than lose momentum.

Craft

Shipped with accessible, keyboard-navigable tabs, responsive layouts, and a caught-and-fixed CSS bug — polish, not just a working demo.

What It's Built With

No frameworks. No local machine. Just discipline.

Every file of Reel Spark was written and committed from a mobile browser.
